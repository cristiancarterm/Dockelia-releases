# ModelDock

### Your local AI control center

**ModelDock** is a desktop application designed to simplify the management of local AI models, engines, and coding agents.

Manage your local AI environment from one clean, lightweight interface.

## Features

- **Ollama management:** Monitor the engine, load and unload models, and manage local AI resources.
- **AI agent integrations:** Manage supported installations of Claude Code, OpenCode, Hermes Agent, and DeepSeek Harness.
- **Resource monitoring:** View memory usage and local engine status.
- **Private installations:** Keep supported agent dependencies isolated from system-wide installations.
- **Update management:** Check for new releases and download verified update packages.
- **Minimalist interface:** Quickly access essential functions without unnecessary complexity.
